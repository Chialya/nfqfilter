# NFQfilter

NFQfilter is a Python-based packet filtering project for Linux-based
network gateways. It uses Netfilter Queue (NFQUEUE) to inspect selected
network traffic and apply filtering decisions in userspace.

## Project status

- **Current development version:** 13.6
- **First public release:** 13.6
- **Release status:** Initial public publication

The public version numbering continues from the existing development
history. Earlier internal development versions are not fully documented
in this repository.
